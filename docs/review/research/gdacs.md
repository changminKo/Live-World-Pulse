GDACS 공개 API 6개 엔드포인트(SEARCH/MAP/geteventdata/getepisodedata/getgeometry/RSS)를 실제 curl로 전수 호출해 검증했다(인증 불필요, 전부 200, GeoJSON). [실측] TC 트랙은 getgeometry에서 과거/예측 구분된 LineString(forecast:true/false) + 타임스탬프 트랙포인트(6h 간격) + 불확실성 콘 + 풍역 폴리곤으로 수신되고, 서태평양 태풍(PODUL-25 대만, JEBI-18 일본 2018)과 에피소드 단위 시점 스냅샷(Time Machine), EQ/TC/FL/VO/WF/DR 전종류, Green/Orange/Red alertscore(1/2/3)→CAP rank 매핑까지 전부 확인 — 판정: (a) PLAN §4.2 GDACS 채택 유효 O, (c) 태풍 데모 성립 O, (b) 대안 불필요. 남은 주의 2건은 SEARCH 기본이 Orange/Red만 반환(alertlevel=Green;Orange;Red 명시 필요)과 트랙포인트가 Point가 아닌 소형 Polygon이라 centroid 추출 필요하다는 것이며, 상세 실측 로그·응답 크기표(트랙 225~288KB, MAP 전종류 1.1MB→lazy fetch 권장)는 reportPath 참조.
